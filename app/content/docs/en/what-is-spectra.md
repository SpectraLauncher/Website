Spectra is a place to find, share and publish content for Minecraft: mods,
plugins, modpacks, shaders, resource packs and building schematics.

## What you can do without an account

Browse everything, read project pages, and download files. Nothing is behind a
sign-up wall.

## What an account adds

- **Follow** projects, so you hear when a new version lands
- **Favourites and collections** — keep things to hand and group them your way
- **Comments** on project pages
- **Friends and shared modpacks**, which the launcher uses
- **Publishing**, once you are set up as an author

## How content is organised

Everything is a **project**. A project has **versions**, and a version has one or
more **files**. When you download something you are downloading a file that
belongs to a version of a project.

That shape is the same for a mod and for a building schematic. What differs is
the metadata: a mod says which loader and game versions it needs, a resource pack
says its pack format, a schematic says its file format.
