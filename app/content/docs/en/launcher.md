The Spectra Launcher is a separate desktop application. It installs and
launches Minecraft, manages instances, and talks to this site for the social
parts.

## What it uses your account for

- **Friends and presence** — who is online, who is playing
- **Sharing a modpack** — export an instance and send a code to a friend
- **Notifications** — the same ones the bell shows here

## Shared modpacks

When you share an instance the launcher uploads it and gives you a short code.
Anyone with the code can import it. A share expires on its own; you can extend it
or revoke it from the launcher.

Sharing a pack does not publish a project. It is a private hand-off between
people, and it does not appear anywhere on the site.
