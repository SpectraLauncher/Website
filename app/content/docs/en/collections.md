A collection is a named list of projects. Use them however you like: a set for
one server, things to try later, favourites by theme.

## Favourites

The star on a project page puts it on a shelf called **Favourites**, which every
account gets the first time it is used. One click, no naming, no choosing.

## Collections

The arrow beside the star opens your collections, with a tick beside the ones the
project is already in. The menu stays open, so one project can go into several
collections without reopening it. You can create a new collection from there
without leaving the page.

## Visibility

Each collection is one of three things:

- **Private** — only you
- **Unlisted** — opens for anyone with the address, but is not on your profile
  and not in search
- **Public** — visible to everyone

## What happens when a project goes away

If a project is made private or taken down, it stays in your collection but stops
being visible to other people. You do not silently lose the entry.

## Following is a different thing

Following a project means you want to hear about new versions. It shows as a
public count on the project. A favourite is a private shelf. They are separate on
purpose.
