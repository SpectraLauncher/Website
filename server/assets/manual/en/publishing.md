A project goes through a few states before anyone else can see it.

## Creating a project

Anyone with an account can start a project, for themselves or for an
organization they may add projects to. **New project** walks through five steps:

1. **Basics** — type, name, address, owner and visibility
2. **License** — required. An open license (MIT, Apache, GPL, MPL, BSD, Creative
   Commons and the like) also needs a link to the source code on GitHub, GitLab or
   Codeberg. All rights reserved needs no link; a license outside the list needs a
   link to its text
3. **Description** — summary, description, categories and an icon. Finishing this
   step saves the project as a draft
4. **First version** — the file people will download. What it says about itself
   fills in the version
5. **Review** — send it to the moderators

You can stop after any step once the draft exists and finish in the project's
settings.

## Draft

Only you and anyone you have added can see a draft. Gallery images, links and
disclosures can be added in the settings at any time.

## Submitted

When it is ready you submit it for review. A submission needs at least one
version — there is nothing to review otherwise. While it is waiting, it stays
private.

## Published, rejected, removed

A moderator either publishes it, or rejects it with a message explaining what has
to change. A rejection is not the end: fix what the message asks for, reply in
the thread, and the project goes back into the queue.

A project is reviewed once. After approval, new versions and edits go live
without waiting, and switching between public, unlisted and private does not send
it back to the queue.

## Unlisted and archived

**Unlisted** opens for anyone holding the address but stays out of search and
listings. **Archived** stays visible and searchable but signals that it is no
longer being worked on.

## The moderation thread

Every project has a thread between its authors and the moderators. It is where a
decision is explained and where you answer. Nobody else can read it.
